## 核心更新

- **SSOT 单一事实源架构上线**：建立严格的品牌 JSON 数据模型，全站所有页面从统一数据源读取套餐价格、节点数量与实测指标，杜绝前后冲突
- **横向对比参数大表**：支持按价格、测速、线路类型、解锁能力进行多维横向筛选
- **深色模式视觉调优**：提升深色背景下的正文对比度与代码高亮可读性，优化 ASCII 决策树移动端横向滚动体验
- **首批标杆品牌收录**：完成 TAG Internet、Nexitally 佩奇、IMMTelecom、FSCloud、速鹰 666、iKuuu 六大代表性品牌的基线测试
